# 模块二与 UI 改版验证

环境：本机 Python 3.10、PySide6 6.11.2、Open3D 0.19.0，XWayland 桌面。

## 已通过

- 7 项 unittest：输入错误、XYZ 统计、源文件/原始点云不变性、闭区间裁切、预览与工作点云分离、重复预处理一致、放宽范围恢复原始点、Reset、撤销、非法范围与空结果保护。
- 真实 GUI：Open3D 在主窗口显示前处于 IsUnMapped；显示后沿 X11 父窗口链可回溯到主窗口，且调整主窗口大小后匹配容器宽度。
- 真实 GUI：5,043 点样例开启 0.5 m Voxel 和 Z ≤ 3.5 m 裁切，预览为 777 点。应用、再次预览、编辑参数使预览失效、撤销、关闭裁切/降采样恢复全部点、Reset 均通过。
- 真实 GUI：无效范围禁用 Preview；空预览禁用 Apply；显示开关、相机更新、关闭通过。

截图由真实 Qt 控件和同一时刻 Open3D 渲染缓冲组合；XWayland 屏幕抓图返回黑图，而 QWidget.grab 不包含原生子窗口，所以不能直接用两者证明整个视窗的像素。单窗口依据独立的原生父子关系与尺寸检查。

未完成的人工验收：鼠标交互手感、超大点云性能、其他显卡/桌面平台。

## 改动影响

保留模块一加载、原始统计与数据显示功能；视图配色改为高度渐变。新增预处理草稿、工作点云和预览状态。UI 样式统一替换，Open3D 隐藏创建后嵌入，避免独立窗口先映射到桌面。

源 PCD 不写入；本次没有修改工作区其他项目。预处理参数当前仅驻留内存，项目保存属于后续模块。
