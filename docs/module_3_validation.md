# 模块三验证记录

已完成：顶部四个标准视角和三维视角按钮、楼层创建/删除/身份编辑、Z Preview / Apply / Cancel、楼层颜色、显示开关、单独查看与查看全部。

## 验证结果

- 11 项核心单元测试通过：原有输入/预处理测试，以及身份唯一性、重命名、删除、Z 闭区间、重叠和空结果、新工作点索引重算、字段校验。
- 模块二真实桌面回归通过：单窗口原生父子关系、调整大小、预处理 Preview / Apply / Cancel / Reset 和源数据不变。
- 模块三真实桌面流程通过：四个视角 front/up 向量符合世界坐标定义，正交模式 FOV 为 Open3D 的 5 度哨兵值；三维视角恢复 60 度透视。
- 5,043 点样例，Z [0,2.5] 和 [3,5.5] 各选出 1,681 点；预览不改变原规则、Apply 提交重命名和 map_id、重复标识阻止预览。
- 预览为空禁止 Apply，修改规则使预览失效；两楼层同时显示具有不同颜色。
- 预处理 Apply 后所有楼层掩码长度匹配新工作点数；Reset 后两层分别恢复 1,681 点，身份不变。
- 单独查看、显示开关和删除通过；原始点坐标保持不变。

截图 `module_3_ui.png` 是 Qt 界面和实际 Open3D 帧缓冲的组合，供排版检查。源文件、工作区其他工程未修改。

## 当前边界
