# 统一楼层处理工作区验证

## 已通过

- 14 项核心单元测试：输入校验、边界裁切、非破坏式处理、楼层身份唯一性、每层独立原始输入、每层草稿和保存状态隔离、重复预览一致性、重置、过期/空预览保护。
- 统计与半径去噪：150 个密集点和 2 个远离噪点的确定性数据，两种方法分别及组合均去掉远离噪点，原始坐标不变；参数异常和统计邻居数过大有明确错误。
- 导出：压缩 PCD 回读点数/坐标一致，rules YAML 含正确身份和去噪参数；拒绝原文件及硬链接覆盖；模拟第二份文件替换失败会恢复原有 PCD/rules。
- 真实桌面：Open3D 仍是主窗口后代；直接发送 X11 1–4 键事件，验证四个正交视角且着色模式不变；名称框中输入 1234 不改变视角。
- 真实桌面：完整地图先裁切后创建 floor1，floor1 仍有全部 5,043 个源点。floor1 独立裁切、降采样并两种去噪后保存，点数少于该层裁切前的 1,681 点。再创建 floor2 重新从 5,043 点开始，独立裁切并保存 1,681 点；floor1 不变。
- 真实桌面：切换对象保留未保存草稿，恢复保存/重置有效；空结果禁止保存；删除保存过的楼层不删除磁盘文件；原始 PCD 哈希保持不变。
